# حزمة تنفيذ موقع د. ملاك السيف
هذه حزمة تعليمات وأصول للموديل، وليست موقعًا مكتملًا أو تطبيقًا قابلًا للتشغيل بعد.

## التشغيل
1. فك ضغط ZIP وافتح مجلد Malak-Website-Kit داخل Google Antigravity.
2. اختر الموديل المتاح في حسابك. الحزمة لا تعتمد على اسم أو إصدار موديل محدد.
3. انسخ محتوى MASTER-PROMPT.md كاملًا في المحادثة.
4. اطلب تنفيذ الموقع داخل نفس المجلد مع الحفاظ على brand وdocs.
5. افتح المعاينة المحلية التي سيجهزها الموديل وراجعها.

## الموجود فعليًا
- برومبت كامل مستقل، وAGENTS.md لترتيب القراءة.
- ملفات توجيه للتصميم والبرمجة والمحتوى والمراجعة.
- مواصفات المسارات العربية والإنجليزية وملف ROUTE.md لكل صفحة.
- لوحتا الهوية الأصليتان ونسخة اللوجو المتاحة كمرجع فقط.
- ألوان وتوكنز CSS وإعدادات التواصل ومحتوى عربي وإنجليزي.
- مسارات خطوط alghraib وSTC وتعليمات الربط.

## ملفات ناقصة وليست مرفقة
تمت إضافة Elgharib Tajarib Taweel بخمسة أوزان OTF من الملف الذي أرسلته. STC فقط غير متاح، ومجلده يحتوي تعليمات للبديل المؤقت. أضف النسخ التي تملك حق استخدامها للويب بصيغة WOFF2 أو TTF أو OTF، مع الترخيص إن توفر.
صورة الدكتورة عالية الجودة واللوجو الأصلي السليم لم يتوفرا أيضًا. صور السيدات في لوحات الهوية ليست صورة الدكتورة ولا حالات علاج.
نسخة اللوجو المرجعية مكتوب بها SURGION، لذلك لا تُستخدم للإنتاج ولا يعدّلها الموديل تلقائيًا؛ يستخدم الاسم نصيًا حتى استبدالها.

## الخطوط
الاسمان مؤكدان منك: alghraib وSTC. توزيع alghraib للعناوين وSTC للنصوص هو اقتراح تنفيذي، ويُراجع بعد فتح ملفات الخطوط. لن يدعي الموديل اكتمال الهوية قبل تحميل الخطين الحقيقيين.
