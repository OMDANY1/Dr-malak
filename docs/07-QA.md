# Acceptance checklist
- [ ] All ten localized routes render; / redirects to /ar; unknown routes/locales produce 404.
- [ ] Header/footer navigation and equivalent-page locale switching work.
- [ ] Arabic document is RTL and English is LTR; mixed phone text is correct.
- [ ] Mobile menu works with keyboard, Escape and touch.
- [ ] CTA opens correct WhatsApp number with properly encoded message; no automatic sending.
- [ ] Telephone and Instagram URLs correct; contact wording does not imply confirmed booking.
- [ ] No absent image/font requests, placeholder links or missing React keys.
- [ ] No moodboard model falsely presented as doctor or patient.
- [ ] Faulty reference logo not shipped as production logo.
- [ ] Real fonts loaded OR fallback explicitly recorded as incomplete branding.
- [ ] Check actual rendered views at 390, 768 and 1440 px in both languages.
- [ ] No clipping, horizontal overflow, obscured mobile content or poor 200% zoom behavior.
- [ ] Color contrast, focus visibility, headings, alt text and reduced-motion behavior checked.
- [ ] No invented credentials, stats, prices, medical promises or testimonials.
- [ ] Build/type checks and available lint checks run; failures fixed or accurately recorded.
- [ ] Browser console reviewed when browser tools are available.
- [ ] docs/HANDOFF.md states what was done and what was not tested.
Do not mark missing assets complete. Tests are implementation checks, not evidence of medical or legal approval.
