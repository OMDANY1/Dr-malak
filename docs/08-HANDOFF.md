# Handoff format to produce after implementation
Create docs/HANDOFF.md with:
1. Implemented pages and interactions.
2. Install/run/build commands actually used.
3. Check results and viewport screenshots when available.
4. Exact missing assets and current fallbacks.
5. Content requiring clinic confirmation.
6. Deployment configuration still needed; no automatic deployment.

Known pending items before implementation:
- Elgharib is included in five inspected weights; separate web license documentation was not supplied.
- STC font binaries, exact variants/weights and web usage permission.
- Approved high-resolution doctor portrait.
- Correct original logo (current reference spells SURGION).
- Confirmation of professional grade and current clinic/consultation details.
- Approval of brief medical descriptions and privacy copy.
These gaps do not block building a useful local preview, but prevent claiming fully finished branding/publication readiness.
