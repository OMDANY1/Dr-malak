# Component and interaction specification
Header: typographic name fallback, current-page navigation, equivalent-page language switch, primary CTA. Sticky with subtle border, not a large floating panel.
Mobile menu: real button with aria-expanded, labeled navigation, Escape close, restore focus, prevent hidden links from receiving focus. Test keyboard and touch.
Hero: 12-column desktop composition; Arabic copy right, image left only when approved. On mobile, heading and CTA remain prominent. One h1 per page.
Buttons: solid red primary, outlined red secondary; min 44px touch height; focus visible; labels describe actual destination.
Specialties: alternate editorial rows or a small restrained group; no repetitive dashboard grid.
Journey: one red field, ivory type, numbered steps with a logical reading order.
FAQ: semantic details/summary is acceptable. Only administrative questions are approved initially.
Footer: public links and brief informational statement, no invented address.
Mobile contact: subtle fixed CTA only if safe-area padding and bottom spacing prevent overlap.
No autopopups, autoplay audio, animated counters, scroll hijacking or obstructive intro screens.
Breakpoints must be driven by content; inspect 390, 768, 1440px and 200% zoom. Use margin-inline/padding-inline and explicit LTR for phone numbers.
